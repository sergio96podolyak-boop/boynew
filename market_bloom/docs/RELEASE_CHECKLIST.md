# PoMarket — Release Checklist

## Product

- [ ] Complete the bakery expansion and at least two additional departments.
- [ ] Add sounds, haptics, onboarding, pause state, and accessibility labels.
- [ ] Test progression and economy with at least 20 external players.
- [ ] Replace temporary vector art with final original art and app icons.

## Monetization

- [ ] Create the AdMob app and rewarded-ad units for Android and iOS.
- [ ] Replace both sample AdMob app IDs and pass production unit IDs at build.
- [ ] Configure Google UMP consent and regional privacy choices.
- [ ] Publish `app-ads.txt`.
- [ ] Create all three store products with matching IDs.
- [ ] Add server-side purchase verification and idempotent fulfillment.
- [ ] Test purchases with Play license testers and Apple sandbox accounts.

## Android

- [ ] Install Android Studio and Android SDK.
- [ ] Create a release upload key and secure it outside source control.
- [ ] Build and test a signed Android App Bundle.
- [ ] Complete Data safety, content rating, ads, and target-audience forms.
- [ ] Run closed testing before production rollout.

## iOS

- [ ] Install full Xcode and command-line tools.
- [ ] Configure the Apple Developer team and signing.
- [ ] Add the app in App Store Connect and upload an archive.
- [ ] Complete App Privacy, age rating, export compliance, and review notes.
- [ ] Test through TestFlight before App Review.

## Store assets

- [ ] Final name, subtitle, description, keywords, and support URL.
- [ ] Privacy policy and terms pages.
- [ ] 1024×1024 app icon without transparency.
- [ ] Required phone screenshots and optional preview video.
- [ ] Support email and marketing contact.
