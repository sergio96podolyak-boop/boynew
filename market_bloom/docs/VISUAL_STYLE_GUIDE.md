# Visual Style Guide

## Design Goal

PoMarket should evolve into a polished 2.5D supermarket experience that feels tactile, warm, and optimistic. The visual language should remain approachable and friendly, but it should feel more intentional, layered, and premium across the entire experience.

## Core Visual Direction

### Style: 2.5D cozy supermarket

The game should feel like a handcrafted miniature world:

- A clear front-facing market scene with layered depth.
- Soft, rounded shapes and readable silhouettes.
- Slightly exaggerated objects that communicate function instantly.
- A visual language that blends cartoon friendliness with tactile materials.

### Mood

The tone should be:

- Cheerful and optimistic.
- Cozy rather than sterile.
- Busy but never overwhelming.
- Rewarding and alive.

## Color System

### Primary palette

- Emerald green: main brand anchor, used for core actions and key surfaces.
- Cream / warm ivory: main environment background and paper-like UI surfaces.
- Soft coral: highlight color for checkout moments and urgency cues.
- Sky blue: shelf and stock-related accents.
- Golden amber: reward and premium signals.

### Usage guidance

- Use the green family for primary gameplay anchors, store identity, and active states.
- Use cream for room surfaces, cards, and calm UI panels.
- Use coral for checkout energy, customer urgency, and “moment to act” states.
- Use gold for money, rewards, achievements, and premium feedback.

## Typography

Use a rounded, friendly sans-serif that supports clarity and warmth.

Recommended tone:

- Bold for headings and important status numbers.
- Medium weight for labels and short UI copy.
- Clear spacing and generous padding to keep the interface readable on mobile.

## UI Principles

- Keep every surface legible at a glance.
- Prefer clear hierarchy over dense information.
- Use rounded corners, soft shadows, and subtle depth.
- Make important elements feel tactile and “touchable.”

## Scene Composition

The market should feel like a place with zones and personality:

- Entrance: the energy point of new customers.
- Shelf zone: core shopping experience and product visibility.
- Storage area: operational backbone of the business.
- Checkout: high-intensity, rewarding action point.
- Expansion zones: future branches and new store areas.

Each zone should have a distinct visual identity while staying within the same family.

## Character and Customer Design

Customers should be visually simple but expressive.

Design principles:

- Distinct silhouettes that are easy to read from a distance.
- Light emotion cues such as posture, product holding, and thought bubbles.
- A strong but limited palette so the player can read the state quickly.

## Motion Language

Motion should support comprehension and delight.

Recommended approach:

- Short easing curves for interface transitions.
- Gentle bounce and sway for store elements.
- Smooth but readable movement for player and customer activity.
- Celebration moments for milestone achievements and sale completions.

## Visual Systems to Add Over Time

### Phase 1

- Better zone framing and labels.
- More expressive checkout and storage visuals.
- Clearer upgrade affordances.
- Subtle environmental props to make the store feel lived-in.

### Phase 2

- Seasonal decoration layers.
- More varied shelf visuals and product categories.
- Improved day/night or weather atmosphere.
- Character-specific customer moods and behaviors.

### Phase 3

- Expanded departments such as bakery, produce, or specialty shelves.
- More immersive ambient effects without cluttering the core gameplay.
- Signature event art and limited-time visual themes.

## Asset and Production Guidance

- Favor a small, reusable visual language over too many one-off assets.
- Create a consistent set of building blocks for shelves, counters, signage, props, and icons.
- Keep UI assets scalable for both mobile and web presentation.
- Preserve the handmade, friendly quality even as the game becomes more polished.

## Visual Quality Standard

The final experience should feel like a game that is:

- polished enough to feel premium,
- simple enough to stay accessible,
- warm enough to be memorable,
- and consistent enough to support long-term growth.
