# 🚀 מאיפה משגרים | Where From?

בוט חדשות טילים ותקיפות לטלגרם (עברית + English)

הבוט סורק כל דקה מקורות חדשות מכל העולם, מסנן רק ידיעות על **שיגורי טילים, רקטות, כטב"מים, תקיפות אוויריות ויירוטים**, מתרגם, ומפרסם בקבוצה/ערוץ טלגרם — **כל הודעה בעברית ובאנגלית**.

## מקורות
- **פיקוד העורף** — התרעות "צבע אדום" בזמן אמת (בדיקה כל 5 שניות). עובד רק כשהבוט רץ משרת/מחשב בישראל.
- **Google News** — חיפושים בעברית ובאנגלית (מכסה אלפי אתרים בעולם).
- Times of Israel, Al Jazeera, BBC World, Kyiv Independent, Ukrainska Pravda, Meduza, ynet מבזקים, וואלה.

**מה נכלל:** שיגורי טילים, רקטות וכטב"מים, **וגם תקיפות** (תקיפות אוויריות, הפצצות, מתקפות רחפנים). זה כולל את **רוסיה ואוקראינה** ועוד כ־25 מדינות: המזרח התיכון, ארה"ב, בלארוס, פולין, קוריאה, יפן, סין, טייוואן, הודו, פקיסטן, סודן ועוד. הבוט מבין עברית, אנגלית, ערבית, רוסית ואוקראינית, ומתרגם הכול לעברית ולאנגלית.

- **ערוצי טלגרם ציבוריים (דיווחי רשת)** — ערוצים, בעיקר בערבית, שבהם אנשים מדווחים על שיגורים בזמן אמת. הבוט מתרגם מערבית לעברית ולאנגלית ומזהה מאיפה דווח השיגור ולאן (ראה למטה).

אפשר להוסיף/להסיר מקורות ב־`DEFAULT_FEEDS` בקובץ `sources.py`, ומילות מפתח ב־`bot.py`.

## הקמה (5 דקות)
1. **יצירת בוט:** בטלגרם פתח את `@BotFather` → `/newbot` → קבל **טוקן**.
2. **יצירת קבוצה/ערוץ:** צור קבוצה (או ערוץ, מומלץ לחדשות) והוסף את הבוט **כמנהל** עם הרשאת שליחת הודעות.
3. **הגדרות:** הוסף ל־`.env`:
   ```
   NEWS_BOT_TOKEN=123456:ABC...
   NEWS_CHAT_ID=
   ```
4. **מציאת chat_id:** שלח הודעה כלשהי בקבוצה, ואז:
   ```bash
   ./venv/bin/python -m war_news_bot.bot --find-chat-id
   ```
   העתק את המספר (מתחיל ב־`-100...`) ל־`NEWS_CHAT_ID`. לערוץ ציבורי אפשר גם `@שם_הערוץ`.
5. **בדיקה בלי לשלוח:** `./venv/bin/python -m war_news_bot.bot --dry-run --once`
6. **הפעלה:** `./venv/bin/python -m war_news_bot.bot`

בהפעלה הראשונה הבוט מסמן את כל הידיעות הקיימות כ"נראו" כדי לא להציף את הקבוצה; מכאן והלאה נשלחות רק ידיעות חדשות.

## הגדרות נוספות (`.env`)
| משתנה | ברירת מחדל | הסבר |
|---|---|---|
| `NEWS_POLL_SECONDS` | 60 | תדירות סריקת RSS |
| `NEWS_OREF_ENABLED` | true | התרעות פיקוד העורף |
| `NEWS_MAX_AGE_MIN` | 90 | להתעלם מידיעות ישנות יותר |
| `NEWS_MAX_PER_CYCLE` | 15 | מקסימום הודעות בסבב |
| `NEWS_CHANNEL_NAME` | 🚀 מאיפה משגרים \| Where From? | חתימה בסוף כל הודעה (ריק = בלי חתימה) |
| `NEWS_CHANNEL_HANDLE` | — | כתובת הערוץ בחתימה, למשל `@WhereFromLive` |

הפקודה מציגה לכל ערוץ ✅ או ❌, כמה פוסטים רלוונטיים נמצאו, ודוגמה.

**שינוי הרשימה (אופציונלי):** `NEWS_TG_CHANNELS=ch1,ch2` מחליף את הרשימה, ו־`NEWS_TG_CHANNELS=off` מכבה את הערוצים. `NEWS_TG_TRUSTED=ch1` מסמן ערוץ נוסף כמהימן.

3. הבוט בודק את הערוצים כל 15 שניות, מסנן רק הודעות על טילים, רקטות, כטב"מים ואזעקות (עברית, אנגלית וערבית) ומתרגם.

**הגנה מפני שמועות:** דיווח מתפרסם רק כש־**2 ערוצים שונים לפחות** מדווחים על שיגור מאותו מקור בתוך 10 דקות. כל ערוץ נוסף רק מעדכן את ההודעה הקיימת ("👥 מדווח ב־3 ערוצים"), כך שלא יוצא ספאם. כל דיווח כזה מסומן **"⚠️ דיווח ראשוני מהרשת — לא מאומת"**.

**זיהוי תוקף ויעד בתקיפות:** למשל "Russian missile strike on Kyiv" או "غارات إسرائيلية على لبنان" יוצגו כ־`🎯 תוקף לפי הדיווח: 🇷🇺 רוסיה ← יעד: 🇺🇦 אוקראינה`.

**זיהוי מקור ויעד:** הבוט מזהה מהטקסט ביטויים כמו "מתימן", "من اليمن", "from Iran" או "לעבר ישראל" ומוסיף שורה: `📍 מקור לפי הדיווח: 🇾🇪 תימן ← יעד: 🇮🇱 ישראל`. המידע נלקח מהדיווח עצמו ולא מחושב.

## הערות
- תרגום: Google Translate (ללא מפתח). אם התרגום נכשל — נשלחת הכותרת המקורית.
- כפילויות: אותה כותרת ממקורות שונים נשלחת פעם אחת (מצב נשמר ב־`data/war_news_seen.json`).
- ערוצים בערבית מפרסמים לפעמים תעמולה או מידע שגוי. לכן יש סימון "לא מאומת" ודרישה לכמה מקורות.
- זה מאגד חדשות אוטומטי — **לא מחליף את אפליקציית פיקוד העורף** להתרעות מצילות חיים.
