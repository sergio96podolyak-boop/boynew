# 🚀 בוט חדשות טילים ותקיפות — טלגרם (עברית + English)

הבוט סורק כל דקה מקורות חדשות מכל העולם, מסנן רק ידיעות על **שיגורי טילים, רקטות, כטב"מים, תקיפות אוויריות ויירוטים**, מתרגם, ומפרסם בקבוצה/ערוץ טלגרם — **כל הודעה בעברית ובאנגלית**.

## מקורות
- **פיקוד העורף** — התרעות "צבע אדום" בזמן אמת (בדיקה כל 5 שניות). עובד רק כשהבוט רץ משרת/מחשב בישראל.
- **Google News** — חיפושים בעברית ובאנגלית (מכסה אלפי אתרים בעולם).
- Times of Israel, Al Jazeera, BBC World, Kyiv Independent, ynet מבזקים, וואלה.

אפשר להוסיף/להסיר מקורות ב־`DEFAULT_FEEDS` בקובץ `sources.py`, ומילות מפתח ב־`bot.py`.

## הקמה (5 דקות)
1. **יצירת בוט:** בטלגרם פתח את `@BotFather` → `/newbot` → קבל **טוקן**.
2. **יצירת קבוצה/ערוץ:** צור קבוצה (או ערוץ, מומלץ לחדשות) והוסף את הבוט **כמנהל** עם הרשאת שליחת הודעות.
3. **הגדרות:** הוסף ל־`.env`:
   ```
   NEWS_BOT_TOKEN=123456:ABC...
   NEWS_CHAT_ID=
   ```
4. **מציאת chat_id:** שלח הודעה כלשהי בקבוצה, ואז:
   ```bash
   ./venv/bin/python -m war_news_bot.bot --find-chat-id
   ```
   העתק את המספר (מתחיל ב־`-100...`) ל־`NEWS_CHAT_ID`. לערוץ ציבורי אפשר גם `@שם_הערוץ`.
5. **בדיקה בלי לשלוח:** `./venv/bin/python -m war_news_bot.bot --dry-run --once`
6. **הפעלה:** `./venv/bin/python -m war_news_bot.bot`

בהפעלה הראשונה הבוט מסמן את כל הידיעות הקיימות כ"נראו" כדי לא להציף את הקבוצה; מכאן והלאה נשלחות רק ידיעות חדשות.

## הגדרות נוספות (`.env`)
| משתנה | ברירת מחדל | הסבר |
|---|---|---|
| `NEWS_POLL_SECONDS` | 60 | תדירות סריקת RSS |
| `NEWS_OREF_ENABLED` | true | התרעות פיקוד העורף |
| `NEWS_MAX_AGE_MIN` | 90 | להתעלם מידיעות ישנות יותר |
| `NEWS_MAX_PER_CYCLE` | 15 | מקסימום הודעות בסבב |

## הערות
- תרגום: Google Translate (ללא מפתח). אם התרגום נכשל — נשלחת הכותרת המקורית.
- כפילויות: אותה כותרת ממקורות שונים נשלחת פעם אחת (מצב נשמר ב־`data/war_news_seen.json`).
- זה מאגד חדשות אוטומטי — **לא מחליף את אפליקציית פיקוד העורף** להתרעות מצילות חיים.
